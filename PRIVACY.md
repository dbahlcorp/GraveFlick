# GraveFlick Privacy Policy

Last updated: August 19, 2026

GraveFlick does not collect, transmit, sell, or share personal information itself. The game does not use advertising identifiers, analytics SDKs, its own user accounts, location services, contacts, cameras, microphones, or third-party tracking.

Gameplay progress, settings, high scores, upgrades, and earned currency are stored only on the player’s device using Apple’s local preferences system. Deleting the app or using the in-game reset option removes this locally stored progress.

## Game Center (optional)

GraveFlick offers optional integration with Apple's Game Center for campaign/survival leaderboards and achievement tracking. This uses Apple's own GameKit framework, not a third-party SDK. If the player is signed in to Game Center, their score and unlocked achievements for a completed run are reported to Apple through GameKit; this only happens with an authenticated Game Center account, and sign-in is handled entirely by Apple's own system UI, not by GraveFlick. Players who don't sign in to Game Center never have this data reported. Apple's handling of data submitted through Game Center is covered by Apple's own privacy policy, not this one.

Questions can be submitted through the project’s [GitHub issue tracker](https://github.com/dbahlcorp/GraveFlick/issues).
